__EXPERIMENTS__

Engineering notes: the first runs on a 4 GB laptop

The first 15 runs, PPO with β = 0, 1, 2 and 4 (three seeds each) and AD, AD + rarity β = 1 and AD + rarity β = 2 (seed 0), were trained on a Windows laptop with an RTX 3050 and 4 GB of GPU memory. Getting the official code to run there took the changes below. All later runs used a Linux laptop with an RTX 5090 (24 GB). There the same code ran, with micro-batching kept only where it was needed to match the first runs' settings or to fit three runs on one GPU. The method's maths is the official code's. Every change below is engineering, and each was checked against the original.
